# 楼宇名称、代号与搜索定位

核对日期：2026-10-05。共 81 个建筑/体量组、65 个公开楼号，地图共 111 个目的地（含游戏新增共享停车区、校园猫活动区、深夜实验室入口、六个校车站和东侧环线连接桥）。

地图“找楼”输入楼名、代号或别名，点结果或 Enter 自动定位镜头并高亮建筑，不移动角色。F / Esc / 返回漫游恢复原视角；随后可导航或空降。C1 不匹配 C10，全角、小写和含空格楼号可用。

## 核对与修正

- C1 与 C8、C10 与 C13 在旧模型中的楼号互换，本次依导览图轮廓及公开地图位置纠正。
- F1–F17 位于北侧生活区，与南侧 C 系列共存；删除错误的 C17/F17、C18/F18 同楼别名。
- 生命科学楼为 E6/E7，基础医学楼为 E8/E9，实验室及工程公告地址优先于导览图误标。
- 科研中心采用校方 E14，拒绝公开地图旧标 E11；E11 属实验动物中心。
- F17 为食堂，F16 为教工之家；不沿用旧模型相反的功能名称。

## v1.4.1 楼号显示补齐

按用户 2026-10-05 提供的校园手绘图核对 C1–C19，原目录已有这些编号，本次补齐其在全校总览和小地图的显示，不改动建筑位置或已有目录身份。全校总览将其余已确认代号的楼宇一并显示为紧凑标牌，生活区楼号优先于其他新增标牌；主要地标仍显示楼名和代号。悬停紧凑标牌可查看完整楼名。标牌避让和引线跟随镜头，密集或小窗口中可能隐藏部分标签，找楼搜索可准确定位。

小地图为全部具有公开 codes 的建筑绘制楼号，放大地图可提高阅读尺寸。搜索与导航继续从共享目录读取，不维护另一套编号，不使用 res-* 等模型 ID 替代公开楼号。参考图没有给出的编号不能仅凭建筑方位推断；以后获得明确来源时同步修改 data/campus.json 与 data/building-directory.json 并运行楼宇核对测试。
