# 地图空降与步行导航

按 M 或点击“地图 · 导航”打开地图。点击地图任意位置选择目的地，或在“找楼”输入建筑名称、楼号、别名；点结果或按 Enter 会定位镜头并高亮建筑，不移动角色。F / Esc 或“返回漫游”恢复原视角。也可展开“地点列表 · 空降 / 导航”选择广场、桥梁与栈道；共 101 个地点。“放大地图”可显示完整校园及选点操作。F 总览中同样可使用地图。

## 空降

点击“空降到这里”，角色立即转移到所选校园位置。服务器验证坐标、寻找安全落点：建筑、水面或已有玩家占据的位置会调整到附近可站立的位置，桥面允许落点。地图外围点击会限制在校园范围内。空降间隔为 1.5 秒。

落点立即同步给其他玩家并保存到账号，退出后再登录仍在该位置。空降不改变血量、击倒数、倒地数或复活保护，不计入倒地，也不能借此回血。

## 导航

选好地点后点击“规划步行路线”。蓝色路线同时显示在三维场景与地图上，目的地标记及剩余距离帮助判断方向；沿路线自行步行即可。建筑目的地设在附近可通行位置，当前模型没有开放楼内空间。

路线避开楼体、水面和校园边界，可经桥面和栈道，也可经开放草地。移动超过约 5 米、偏离路线、回到起点、空降或随机复活后自动重新规划；距终点 3 米以内提示到达并结束。点路线卡片的 × 可取消导航；再选地点可替换目标。选择地图位置会停下行走并退出固定相机视角。

若所选位置处在没有步行出口的封闭区域，会明确提示无法规划，可改选入口附近或空降。导航只提供指引，不自动移动角色；服务器继续判定所有移动碰撞。

## 实现与验证

共享场景与碰撞数据生成 2 米步长的八方向连通网格；每条网格边与平滑后的路线逐段检查障碍。浏览器独立 Worker 运行 A*，规划不阻塞渲染。`npm run build` 根据场景及碰撞规则的哈希自动更新 `data/navigation.json`。

`tests/navigation.test.ts` 检查快速碰撞与实际物理一致、安全落点、101 个地点的可达性、四条路线连续行走，以及真实 Socket.IO 空降同步与数据库恢复。`tests/e2e/navigation.spec.ts` 检查地图选点、地点搜索、双页面同步、重登录、三维与地图路线、重新规划、到达、取消及放大地图。实际结果见 `reports/navigation-route-audit.json`、`reports/unit.log` 与 `reports/browser-summary.json`。
