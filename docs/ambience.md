# 昼夜、天气与校园彩蛋（v1.6.0）

默认由服务器快照时间推导全员共用的校园时钟。现实 24 分钟对应校园一天，晴、多云、晴、雨、多云、晴每 6 分钟轮换；属于游戏氛围，不是杭州实时天气，也不是现实北京时间。断线恢复或服务器重启不会重新从白天开始。

左上角天气卡可展开。窄屏若地图打开会暂时隐藏天气卡，点“地图 · 导航”收起地图即可使用。时段和天气默认“自动 · 全员同步”；清晨、白昼、黄昏、深夜和天气预览仅改变当前页面画面，其他玩家继续使用自己的选择。重新加载页面恢复自动模式。夜间保留足够环境光，晴夜出现星空，路灯亮起；雨天显示相机附近的轻量雨点。天气不改变跑速、汽车抓地力、血量或竞技判定。

## 深夜实验室

搜索“深夜实验室”或展开天气卡点击“寻找深夜亮窗”可以定位。搜索结果支持原有空降和步行导航。校园 21:00–05:00，工学楼 E1–E3 一扇北侧窗亮起，附近出现“实验还没跑完…”的小牌子；走到牌子 18 米内会看到提示。可选深夜预览立即查看。彩蛋由游戏创作，不表示现实实验室的值班情况；目前仍是室外场景，不能进入实验室。

## 校园流浪猫

庭园及周边小径有四只不同毛色的校园猫，自动散步、休息、摇尾巴。搜索“猫”“流浪猫”或“校园猫”可定位庭园猫的活动区并导航、空降；天气卡也有定位按钮。步行靠近 4 米内出现“和校园猫打招呼”按钮，点击后猫头顶出现三秒爱心，两秒内不能重复触发。猫不会受拳击伤害，也不阻挡行人或车辆。请在现实校园里温柔对待动物。

猫的路线和姿态按共用服务器时间计算，迟加入玩家看到同一活动阶段；打招呼的爱心只在当前页面显示，不保存到账号。游戏新增猫、牌子与亮窗是彩蛋场景，不是对现实动物位置或建筑用途的精确标注。

## 开发规则

- `shared/atmosphere.ts` 定义昼夜与天气周期，使用快照时间加收包后时间差。预览使用独立本地选项，不修改快照或账号。
- `shared/wildlife.ts` 定义经过碰撞检查的猫路径、连续运动与停顿，以及彩蛋位置；`shared/destinations.ts` 提供搜索和导航入口。
- `client/ambience.ts` 管理光照、天空颜色、星空、路灯发光、650 个附近雨点、四只程序化猫和深夜亮窗。不要每帧重建材质、纹理或几何，不引入外部图片、在线天气服务或个人数据。
- 动物仅作环境装饰，不写入在线玩家、不计入人数、不参与服务器战斗，不新增账号数据库字段。
- 验证周期确定性、所有猫位置不穿障碍、休息切换连续、彩蛋入口可通行；浏览器验证双页面同步、独立预览、搜索空降、提示与打招呼，记录实际截图与渲染错误。
- 当前雨点是氛围粒子，没有屋檐遮雨判定、真实水滴碰撞或水面涟漪；亮窗和路灯使用轻量发光几何，不新增大量动态光源。

针对本功能运行 `npm run test:e2e -- tests/e2e/ambience.spec.ts`；无参数则运行完整浏览器回归。测试房间使用独立临时存档，退出时停止并清理。
