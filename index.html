操作速查

行走与视角

WASD / 方向键：行走
按住 Shift：加速行走
拖动鼠标：转动视角
滚轮：缩放
F：全校总览 / 返回
Esc：关闭面板 / 返回跟随视角

地图与界面

M：打开 / 收起地图
输入楼名或楼号：搜索
点击结果：定位建筑
点击地图：选择位置
点击「空降到这里」或「规划步行路线」
左侧 ＋ / −：展开 / 收起操作
E：打开招呼面板

动作

J / 空格：轻拳
L：重拳
按住 K：格挡
Q：按移动方向闪避
也可点击左侧展开后的动作按钮
靠近可交互对象：点击出现的按钮

车辆操作

R：上 / 下汽车
驾车时 W / S：前进 / 倒车
A / D：转向
空格：刹车
B：上 / 下校车
